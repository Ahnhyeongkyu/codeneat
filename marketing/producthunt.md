## Launch Day

**Tagline:**
Developer tools that never see your code

**Description:**
Every time you paste code into an online formatter, it gets sent to an external server. CodeNeat fixes this. All 8 tools — JSON Formatter, Base64 Encode/Decode, URL Encode/Decode, Regex Tester, Diff Checker, JWT Decoder, SQL Formatter, and Hash Generator — run entirely in your browser. No server processing. No data transmission. No account required. Open your DevTools and verify for yourself: zero network requests for any tool operation. Built with Next.js and TypeScript, open source on GitHub, and works offline after first load.

**First Comment (by maker):**

Thanks for checking out CodeNeat.

I built this after catching myself pasting production credentials into online JSON formatters. Most popular developer tools process your input on their servers — your API keys, database credentials, and proprietary code get sent over the wire for what amounts to a string manipulation.

Every tool on CodeNeat runs as a pure JavaScript function in your browser. There is no backend processing endpoint. You can disconnect from the internet after loading the page and every tool still works.

The entire codebase is open source, so you can audit exactly what happens with your data (spoiler: nothing leaves your machine).

I would love your feedback on the tools and any suggestions for what to build next. A Chrome extension is in progress.

**3 Key Features to Highlight:**

1. **100% Client-Side Processing** — All 8 tools run in your browser. No server requests. Verify in DevTools.

2. **Open Source & Free** — Full source code on GitHub. No account, no paywall for core tools. MIT licensed.

3. **Works Offline** — Load once, use anywhere. Every tool functions without an internet connection.
